# NBA Lab

**Rewrite NBA history, then simulate what changes next.**

NBA Lab is a point-in-time basketball simulation and counterfactual analysis engine. Pick an as-of date, reconstruct the league using only information available before that date, then branch the timeline and simulate thousands of paired futures through the regular season, play-in, playoffs, and Finals.

The current signature interaction is **Flip a Game**: reverse one completed historical result and measure how the model's expected wins, seeding, playoff probability, and championship probability move across the league.

## Why this is not another stats dashboard

The interesting output is generated by computation, not lookup or LLM prose:

1. rebuild a leakage-safe historical team-strength state;
2. run Monte Carlo futures from that exact date;
3. alter one historical fact;
4. rebuild the alternate state;
5. reuse common random numbers across both worlds;
6. show the downstream distributional delta.

The model is deliberately simple today. Complexity has to earn promotion through chronological backtesting.

## Run it

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e '.[dev,data]'

# Recommended for the historical demo: freeze the completed 2025-26 season.
nba-lab-sync --season 2025-26

nba-lab
```

Open `http://127.0.0.1:8765`.

Without a local official snapshot, the UI starts with a clearly labeled deterministic synthetic league so the product remains testable offline.

## What works now

- point-in-time Elo with explicit future-leakage protection;
- chronological Brier/log-loss/accuracy backtest scaffold;
- 30-team East/West metadata;
- Monte Carlo remaining-season simulation;
- No. 1 seed, top-6, play-in and playoff probabilities;
- play-in + best-of-seven playoffs + Finals per simulation;
- championship probabilities;
- paired counterfactual simulation using common random numbers;
- historical game-result branching;
- abstract strength intervention kept separate from player claims;
- official `scheduleLeagueV2` parser + freeze script;
- FastAPI + lightweight browser UI;
- deterministic synthetic fallback;
- automated regression tests.

On the offline synthetic 30-team fixture, a 10,000-trial **paired** season + postseason comparison runs in about 2.6 seconds on the development sandbox.

## Next model layers

The architecture intentionally leaves room for increasingly basketball-specific models without changing the counterfactual product surface:

- player impact / RAPM with uncertainty;
- availability and minutes-aware team strength;
- lineup estimation for unseen combinations;
- possession-state models;
- game-state branching (`rewrite from 6:42 Q4`);
- integration with the existing MVP-ranking work for simulated award-race distributions.
